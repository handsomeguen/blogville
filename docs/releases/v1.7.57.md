# Blogville v1.7.57 (2026-11-23)

미국 데이마켓(한국 낮) 가격이 다시 야후 파이낸스(블루오션) 값으로 나와요.

## 바뀐 것

- 📈 야후 실시간 연결이 데이마켓 체결을 보내지 않게 되어, 야후 시세 API에서 데이마켓 가격을 받아요. 그동안은 크라켄 주식 토큰 참고 가격만 보였어요.
- 🔧 서버가 야후 시세 화면을 받다가 응답 헤더가 너무 커서(약 43KB) 실패하던 문제를 고쳤어요.
- 🔧 시세 점검 주소(/api/stocks/status)에 야후 시세 API 결과와 실패 원인을 함께 보여 줘요.
