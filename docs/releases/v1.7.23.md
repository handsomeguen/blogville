# Blogville v1.7.23 (2026-10-15)

광주·전남 식당의 블로그 후기가 거의 안 뜨던 문제를 고쳤어요.

## 한눈에

| | 바뀐 것 |
|---|---|
| 🛠 광주·전남 후기 | 카카오 주소가 "전남광주통합특별시 …"로 바뀌면서 후기 검색어가 어긋났어요. 블로거가 쓰는 "광주 서구", "목포"로 찾아요 |
| 🗺 주소 줄임 | "전라남도 목포시" → "전남 목포시", "전남광주통합특별시 서구" → "광주 서구"처럼 짧게 보여요 (경기·경북 같은 다른 도도) |
| 📝 상세 후기 표시 | 후기 머리에 "최근 1년 N편"이 나오고, 후기가 없을 때도 1년 기준으로 안내해요. 이름만 같거나 광고라 뺀 글이 있으면 몇 편 뺐는지 알려 줘요 |

## 🛠 무엇이 문제였나요

- 2026년부터 카카오 지도 주소가 "전남광주통합특별시 서구 상무오월로…"처럼 와요.
- 그래서 후기 검색어가 "마피아 전남광주통합특별시 서구"가 되어 네이버·티스토리·다음 어디서도 글이 거의 안 잡혔어요. 지역 인기와 내 주변의 "블로그 많이 올라온 순"도 같은 이유로 0편으로 셌어요.
- 이제 광주의 구는 "광주 ○구", 옛 전남 시·군은 "목포"·"순천"처럼 시·군 이름으로 찾아요.
- 짧은 이름 식당(예: "마피아")도 "광주 마피아 맛집"처럼 도시 이름이 든 글은 그 식당 이야기로 봐요. 게임·영화 글은 그대로 빠져요.
